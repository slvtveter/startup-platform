# Разборы паттернов

Каждый файл — «готовый ответ» на вопрос «как это делают лучшие и что из этого брать Envola». Скилл читает его
первым, прежде чем снимать сайты заново. Шаблон: `../../references/pattern-template.md`.

| Паттерн | Файл | Статус |
|---|---|---|
| Карточка лида / отклика / кандидата | `lead-card.md` | полный, есть решение (PR этого скилла) |
| Карточка человека | `person-card.md` | полный |
| Карточка стартапа / вакансии | `startup-card.md` | полный |
| Каталог, фильтры, поиск | `catalog.md` | полный |
| Первый экран главной | `home-hero.md` | полный |
| Профиль человека | — | собрать: GitHub, Peerlist, Toptal (детальная), hh резюме; пока см. `docs/research/design-audit-best-in-class.md` § «Профиль» |
| Страница стартапа | — | собрать: YC detail (снят), Wellfound company, Хабр вакансия; пока см. тот же документ § «Страница стартапа» |
| Пустые состояния | — | собрать по ходу задач; принципы в `references/rubric.md` |
| Онбординг, вход | — | собрать: Peerlist, Contra, YC, Т-Образование |
| Чат | — | собрать: Telegram, Superhuman, Хабр Карьера; закрытые разделы — только по памяти или через Claude in Chrome |

Когда задача касается паттерна без файла — workflow «новый паттерн» в `SKILL.md`, шаг 2: снять, посмотреть
листами, написать файл. Пустые места не заполнять «по памяти» без пометки об этом.
