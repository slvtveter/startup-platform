# Startup Platform

Платформа, где стажёры и выпускники в IT находят стартапы для первого реального опыта, а основатели — команду.

**Стек:** Next.js + Tailwind + shadcn/ui · FastAPI + SQLAlchemy 2 + Alembic · PostgreSQL 17 · Caddy · Docker Compose.

## О проекте
**Проблема.** Новичку в IT нужен первый реальный опыт, но без опыта не берут на стажировку. Ранним стартапам нужны люди, но платить рынок им нечем. Обе стороны ищут друг друга по чатам и знакомым.

**Решение.** Каталог стартапов с открытыми «местами в команде»: роль, нагрузка в часах, условия (бесплатно, деньги, доля) и что человек получит. Новичок откликается в одно действие, основатель отвечает. После взаимного согласия обе стороны видят контакты друг друга.

**Для кого:**
- стажёры и выпускники (дизайн, разработка, аналитика, маркетинг) — ищут проект для портфолио;
- основатели ранних стартапов — собирают команду.

## Что уже сделано (MVP)
- **Новичок:**
  - профиль с навыками, фото и публичной страницей;
  - каталог стартапов и людей с фильтрами и поиском с учётом русских словоформ;
  - подбор «подходит вам»;
  - отклик и статусы отклика с подсказкой «что дальше»;
  - еженедельное письмо с новыми ролями под профиль.
- **Основатель:**
  - карточка стартапа с местами в команде и шаблоны ролей;
  - входящие отклики и приглашения людей;
  - напоминание, если отклик ждёт ответа больше 48 часов;
  - набор закрывается сам, когда команда собрана.
- **Платформа:**
  - вход по email и GitHub, подтверждение почты;
  - письма через фоновую очередь с отпиской в один клик;
  - жалобы и модерация;
  - SEO: SSR, sitemap, OG-картинки.
- **Админка:**
  - воронка и метрики гипотез H1–H8;
  - удержание пользователей на 7-й и 30-й день, выгрузка в CSV;
  - перенос чужих стартапов на платформу, справочники.
- **Дизайн:**
  - исследование (JTBD, CJM, 10 референсов, доска Miro);
  - собственная дизайн-система «место в команде»;
  - проверки доступности (axe) и мобильной вёрстки в CI.
- **Инфраструктура:**
  - Docker Compose, Caddy с HTTPS и CSP;
  - контейнеры приложения без root;
  - бэкапы БД и файлов;
  - CI: линтеры, 61 тест API, E2E, сборка prod-образов, проверка уязвимостей зависимостей.

## На каком этапе
MVP готов и проверен локально и в CI (фазы 1–6, задачи в Jira, проект KAN). **Ещё не развёрнут:** нужны VPS и домен.

Дальше:
1. Купить VPS и домен, настроить по [docs/deploy.md](docs/deploy.md) и выкатить staging, затем prod.
2. Подключить настоящий SMTP и мониторинг (KAN-109).
3. Привести первых основателей и новичков и проверить гипотезы по метрикам в `/admin`.
4. Задачи для команды: ML-подбор (KAN-90), SEO, дизайн-ревью.

Как устроена система и онбординг для новых людей — [docs/architecture.md](docs/architecture.md).
Дизайн и исследование — [docs/ux](docs/ux), безопасность — [docs/security.md](docs/security.md), деплой — [docs/deploy.md](docs/deploy.md).

## Быстрый старт
Нужны Docker, [uv](https://docs.astral.sh/uv/) и Node 22.

```bash
make setup   # зависимости
make dev     # всё в Docker
```

- Сайт: http://localhost:8080
- API docs (Swagger): http://localhost:8080/api/docs
- Почта (Mailpit): http://localhost:8025

Демо-данные: `make seed`. Аккаунты (пароль `demo12345`):

| Email | Роль |
|---|---|
| `maria@example.com` | дизайнер, ищет первый опыт |
| `alina@example.com` | основатель «ВкусноРядом», есть входящие отклики |
| `admin@example.com` | администратор (`/admin`) |

Тесты: `make test` (API, pytest), `cd apps/web && npx playwright test` (E2E, нужен `make dev` + `make seed`).

Остальные команды: `make help`. Деплой: [docs/deploy.md](docs/deploy.md). События аналитики: [docs/events.md](docs/events.md). Правила работы: [AGENTS.md](AGENTS.md). Описание продукта: [docs/startup-idea.md](docs/startup-idea.md).
