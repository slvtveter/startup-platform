# Админка

Адрес: **https://envola.ru/admin**. Пункт «Админка» появляется в меню аватара у аккаунтов с правами администратора.

## Кто админ и как выдать права

Права — флаг `users.is_admin`. Выдаются только из консоли сервера:

```bash
make create-admin email=you@example.com          # локально
# прод (на сервере, в /opt/startup-platform):
export IMAGE_TAG=$(cat .deployed-tag)
docker compose -f compose.prod.yml --env-file .env.prod exec api python -m app.scripts.create_admin you@example.com
```

Аккаунт должен уже существовать (сначала зарегистрироваться на сайте). Снять права — `update users set is_admin=false where email=…`.
Админа нельзя заблокировать из админки.

## Вкладки

| Вкладка | Что там | Что можно сделать |
|---|---|---|
| **Обзор** | Цифры за 7/14/30 дней только по настоящим пользователям (без демо и тестовых): пользователи и новые, кто заходил за 7 дней, профили в каталоге, стартапы в наборе, отклики (и сколько ждут ответа), сообщения, жалобы, обратная связь. График регистраций по дням и пять последних пользователей | — |
| **Модерация** | Жалобы на стартапы и профили (кнопка «Пожаловаться» на страницах) и сообщения из формы «Сообщить о проблеме или идее» в подвале | жалобу — «Решено» или «Отклонить» |
| **Пользователи** | Фильтр «Все / Настоящие / Демо», поиск по почте и имени; у каждого — роль, в каталоге ли, подтверждена ли почта | заблокировать / разблокировать (блокировка сразу завершает все сессии); **удалить насовсем** с подтверждением — профиль, стартапы, отклики и файлы. Админа удалить нельзя |
| **Стартапы** | Все стартапы со статусом и почтой владельца | скрыть из каталога или вернуть. «Перенести стартап на платформу»: оформить чужой открытый проект за основателя; он получит его, когда зарегистрируется с указанной почтой |
| **Справочники** | Роли и навыки | добавить, переименовать (slug и ссылки не меняются), слить дубликаты |
| **Журнал** | Последние 50 действий админов: кто, что, когда | только просмотр |

Все действия админов пишутся в таблицу `admin_actions` (вкладка «Журнал»).

Вкладки грузят только свои данные; пока они идут, показывается скелетон. Воронка, гипотезы и когорты из интерфейса убраны (не настраивались), их API остались: `/api/admin/metrics`, `/hypotheses`, `/cohorts`, CSV — `/api/admin/export`.

## Чего в админке нет (делается иначе)

- Стартап удаляет его владелец в редакторе; админ может только скрыть его.
- Переписка пользователей админам не видна.
- Рассылки: еженедельная подборка уходит сама (воркер), вручную не запускается.
- Аналитика поведения — в Яндекс Метрике (`docs/analytics.md`), здесь только продуктовая воронка из своих событий (`docs/events.md`).
