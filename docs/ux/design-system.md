# Дизайн-система v2

Основа: исследование в `docs/ux/research.md`. Токены живут в `apps/web/src/app/globals.css`, компоненты в `apps/web/src/components`.

## Идея

Главная единица интерфейса — **место в команде**. Человек приходит не за стартапом, а за конкретным местом в нём.

- Занятое место — чернильный квадрат с инициалами (`<Seat filled />`).
- Свободное место — жёлтый «маркер» с пунктирной рамкой (`<Seat filled={false} />`).
- Состав команды одной строкой — `<SeatRow filled open />`.

Маркер `--marker` используется **только** для свободных мест и выделения «что получишь». Если жёлтое появляется в другом смысле, оно перестаёт что-то значить.

## Цвета

| Токен | Значение | Роль |
|---|---|---|
| `--background` | `#ffffff` | бумага |
| `--secondary` / `--muted` | `#f1f2f7` | поверхности панелей, доска мест |
| `--foreground` | `#121633` | чернила: текст, занятые места, основные кнопки |
| `--muted-foreground` | `#565b77` | вторичный текст (контраст 6.6:1 на белом) |
| `--brand` | `#3d3df5` | ультрамарин: главное действие экрана, ссылки (6.6:1 на белом) |
| `--marker` | `#ffe45e` | свободное место |
| `--marker-soft` / `--marker-ink` | `#fff6c2` / `#5a4700` | блок «что получишь» |
| `--border` | `#e2e4ec` | линии и рамки |

## Шрифты

- **Unbounded** (500, 600) — только `h1` и `h2`. Широкий, с характером; на мелком тексте не используем.
- **Golos Text** — весь интерфейс и текст.

Оба подключаются через `next/font` и раздаются с нашего домена.

## Правила

1. Одно главное действие на экран: оно `brand`, остальные `outline` или `ghost`.
2. Без надзаголовков капсом, без `→` в тексте кнопок, без декоративной нумерации 01/02/03.
3. Метаданные пишем через запятую, а не через `·`.
4. Пустое состояние всегда предлагает действие.
5. Фильтры — чипы-ссылки: работают без JS, состояние в URL.
6. Мобильная версия: на 375px нет горизонтального скролла. Сетки задаём с `grid-cols-1`, чтобы длинный контент не раздувал колонку.
7. Фокус с клавиатуры виден всегда (`:focus-visible`), `prefers-reduced-motion` отключает анимации.
