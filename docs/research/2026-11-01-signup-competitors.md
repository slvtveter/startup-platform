# Регистрация и онбординг: как у конкурентов (2026-11-01)

Сняты первые экраны регистрации (Playwright, 1280px): hh.ru, Хабр Карьера, getmatch, Wellfound, Contra, Peerlist (за Cloudflare), YC Work at a Startup (адрес регистрации — 404).

| Сервис | Первый экран | Пароль | Соцсети | Согласия | Что спрашивают после |
|---|---|---|---|---|---|
| hh.ru | одно поле «Телефон / Почта» → «Дальше» | нет, код | да (+3) | строка «Продолжая, вы принимаете…» | роль, резюме по шагам |
| Wellfound | развилка «ищу работу / нанимаю» **до** аккаунта | Google / почта | Google | строка | профиль кандидата по шагам |
| Contra | «Continue with Google» + почта | нет | Google | строка | роль, ниша |
| Хабр Карьера | вход через Хабр-аккаунт | общий Хабр ID | Хабр ID | общий | профиль специалиста |
| getmatch | Telegram-бот | нет | Telegram | в боте | параметры поиска в боте |
| **Envola (сейчас)** | почта + пароль + одна галочка публикации | да, + код | выключены | строка под кнопкой | профиль (3 шага) → «Что дальше?» |

**Консенсус:** одно-два поля на первом экране, вход через соцсеть рядом, согласия — строкой «Продолжая, вы принимаете», пароль либо не нужен (код), либо через соцсеть. Профиль заполняется уже после аккаунта по шагам.

## Что у нас уже совпадает с лучшими
- Согласия строкой у кнопки, одна галочка — только та, что требует закон (ст. 10.1).
- Сначала аккаунт, потом профиль по шагам, потом выбор, чем заняться (как hh и Wellfound после регистрации).
- Код из письма вместо ссылки — как у hh.

## Что сделано сейчас
- Подсказка опечатки в почте («gmial.com → gmail.com?») — частая причина «код не пришёл».

## Рекомендации (по убыванию эффекта)
1. **Включить вход через Telegram** (код уже есть, нужен бот в BotFather и `TELEGRAM_BOT_TOKEN` в `.env.prod`, домен бота — envola.ru). Для студентов это самый короткий путь: ноль полей.
2. **VK ID** — второй по охвату вход в РФ (нужно приложение VK и `VK_CLIENT_ID`).
3. **Регистрация без пароля** (только почта → код, пароль можно задать потом в настройках) — как hh и Contra; минус одно поле и одна причина бросить форму. Требует доработки API.
