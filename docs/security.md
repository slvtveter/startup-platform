# Безопасность

## Что проверяется автоматически
- **Уязвимости зависимостей (KAN-103):** в CI `pip-audit` по `uv.lock` (runtime) и `npm audit --omit=dev --audit-level=high`. PR не мержится, если в runtime-зависимостях есть известная уязвимость.
- **Доступность и вёрстка:** axe на ключевых страницах (`e2e/visual.spec.ts`).
- **CSP prod-сборки:** браузерная проверка в джобе `images` (`e2e/prod-csp.spec.ts`).

## Решения
- **Свежие релизы.** По умолчанию не берём версию моложе двух недель (защита от сломанных и подменённых релизов). Но если в текущей версии есть известные уязвимости, обновляемся сразу. Так было с Pillow 12.3 → 13.0: 37 advisories, а библиотека разбирает картинки от пользователей.
- **Исключения.** Если уязвимость нельзя закрыть обновлением, запишите её сюда: пакет, advisory, почему не применимо к нам, когда пересмотреть. Сейчас исключений нет.
